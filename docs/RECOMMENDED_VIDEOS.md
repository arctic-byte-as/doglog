# Recommended Videos service (DL-058)

From the trainer dashboard, open a customer's Services & courses and enable Recommended Videos. Choose videos from the saved Skills Library using subject/title search, or add a YouTube link with a subject, title and optional practice note. Save services & courses saves the assignment and video collection together. Each collection is specific to one customer; changing it does not edit the shared Skills Library. Up to 30 recommendations are supported. Remove a recommendation to stop sharing it. Disabling the service hides the saved collection; re-enabling restores it. Incomplete unsaved video drafts are not saved when the service is disabled.

The customer home summary includes a full-width Recommended Videos card when assigned. It reuses the Skills Library's searchable thumbnail grid (one tile per phone row) and renders the selected video inline inside the summary, with its practice note. No dialog or page change is required. The optional service detail page provides the same collection. English/Norwegian service labels and empty-state guidance are included; trainer-written subjects/titles/notes are preserved as entered. The original Skills Library still uses its existing dialog player.

Implementation: RECOMMENDED_VIDEOS uses the existing CustomerServiceAccess mechanism. Per-customer video JSON uses AppContent key `customer-videos:<customerId>`; no migration is needed. The trainer-scoped GET `/api/customers/[id]/videos` requires admin mode, a trainer record and a dog assignment to the target customer. The existing trainer services PUT optionally accepts `recommendedVideos` and updates it with service access in one transaction. Omitting videos preserves saved content. URLs are validated as individual YouTube videos and canonicalized; titles, subjects and notes have length limits. Customer pages read only their authenticated customer's collection and only with the service enabled. Admin customer deletion also deletes the recommendation record. A failed video load disables save and offers Retry, avoiding accidental overwrites.

## Skills Library allocation (DL-059)

The trainer Skills Library now includes a Recommend to customer sidebar panel. Select a customer, then tick videos from the selected core subject and Save recommendations. Changing core subjects retains the current selection across subjects. Existing recommendations reload on customer selection, including any custom videos; toggling only changes the matching subject/title/YouTube video. Lessons without a valid YouTube URL are disabled with guidance to add one. Saving enables RECOMMENDED_VIDEOS while preserving every other assigned service. Unticking removes the matching recommendation; an empty collection remains an enabled service with customer guidance. Switching customers discards unsaved selections rather than carrying them to another customer.

PUT `/api/customers/[id]/videos` uses the same trainer/customer scope as GET, validates the collection and atomically saves videos plus the Recommended Videos access record without replacing other services. The trainer Skills Library's customer selector only includes customers with dogs assigned to that trainer. The shared skills content is not edited by ticking a recommendation. This complements the Services & courses editor, which still supports custom links and notes.

DL-059 validation: optimized build and browser/API tests pass for customer selection, subject checkbox persistence after reload, preserving custom notes and other subjects, unticking, automatic service enabling without clearing private training, and anonymous/customer/foreign-trainer PUT denial. ## Course and video summary layout (DL-060)

When courses and Recommended Videos are both assigned, the home summary groups all course cards in the left column and the video card in the right column, aligned at the top from 1024px. Phones stack the sections. Other assigned services follow underneath. Course week lists and their preview sit inside a native details dropdown, collapsed initially. Inline recommendation thumbnails use up to two columns to stay readable in the narrower panel; the standalone Skills Library grid retains its existing layout.

The optimized build passes.
