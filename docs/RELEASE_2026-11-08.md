# Course scheduling release — 8 November 2026

User-authorised publication of the reviewed course scheduling design to production and main after normal tests. Release adds durable course runs, prescribed-week sessions and owner/dog enrolments; weekly/fortnightly/manual cadence; automatic remaining-week generation; All courses management; and distinct blue course sessions in the shared customer diary and course calendars.

The Dev design used temporary client state. The release replaces that on Services → Courses with persistent trainer-scoped APIs. New groups and enrolments survive reload. Customer visibility requires both enrolment ownership and current ownership of the enrolled dog. Writes validate the catalog course/week, times, dates, session IDs, payload limits and trainer assignment. Existing-group edits use updatedAt concurrency checks. Group/session/enrolment changes are transactional. Enrolling an owner grants the corresponding course-content service without removing any existing service grants; unenrolling removes calendar visibility but preserves separately assigned content access. No email/notifications are sent. Session wall-clock date/time is stored with the group's Europe/Oslo timezone.
