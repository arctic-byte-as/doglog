# MVP Scope

## Goal

Build the smallest useful version first.

---

# Phase 1 Features

## Authentication
- trainer login
- secure sessions

## Dog Profiles
- create/edit dogs
- owner information
- basic metadata

## Behaviour Logging
- behaviour category
- severity
- triggers
- notes
- timestamps

## Consultation Logging
- session notes
- interventions
- recommendations

## Dashboard
- recent incidents
- dog history
- quick summaries

---

# Explicitly Excluded From MVP

- AI recommendations
- advanced analytics
- real-time collaboration
- offline sync
- complex permissions
- marketplace features
